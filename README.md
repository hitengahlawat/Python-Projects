## Projects Included

### 1. Rock Paper Scissors Game
A classic Rock-Paper-Scissors game played against the computer.

#### Features

### 2. Number Guessing Game
A simple game where the computer generates a random number and the player tries to guess it.

#### Features
- Random number generation
- User input handling
- Hints for higher/lower guesses
- Score/attempt tracking
- speaking agent also included
